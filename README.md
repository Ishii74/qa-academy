# QA Academy

QAのテスト計画・テスト設計を体系的に学び、模擬QAプロジェクトで成果物作成まで練習するReact/Vite学習アプリです。

## 主な機能
- 5章・22Lesson
- 章末課題、採点、模範解答、用語辞典
- 音声読み上げ＋ハイライト連動
- 予約システムのインタラクティブデモ
- 模擬QAプロジェクト、Excel出力
- スマホ／PWA対応、ホーム画面用アイコン

## GitHubへ公開
このフォルダの中身をリポジトリへアップロードしてください。
アップロード後、**Settings → Pages → Build and deployment → Source → GitHub Actions** を選択すると、同梱のWorkflowがビルド・デプロイします。

## ローカル起動
```bash
npm install
npm run dev
```

## 本番ビルド
```bash
npm run build
```

## 注意
`.env`、APIキー、パスワードなどの機密情報はコミットしないでください。
